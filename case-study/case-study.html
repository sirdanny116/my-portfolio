CASE STUDY

Savanna Table

Restaurant Website Design & Front-End Development

A modern restaurant website designed to create a simple, attractive and user-friendly experience for customers browsing the menu and making reservations.

01. Project Overview

Savanna Table was created as a modern restaurant website concept focused on combining visual appeal with a simple and practical user experience.

My Role UI/UX Designer & Front-End Developer
Tools Figma, HTML, CSS, JavaScript, VS Code
Platform Responsive Web
Project Personal Portfolio Project

02. The Challenge

Restaurants need a digital experience that allows customers to quickly understand what they offer, explore their menu and take action without confusion.

The goal was to create a restaurant website that felt modern and premium while remaining easy to navigate on both desktop and mobile devices.

03. Project Goals

  • Create a modern and visually appealing restaurant experience.
  • Make navigation simple and intuitive.
  • Make the website responsive across different screen sizes.
  • Make table reservations easy for customers.
  • Create a strong visual identity for the restaurant.
